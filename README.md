**Zenith AI** is an intelligent chatbot built with Python, Streamlit, and Google Gemini 2.5 Flash for the **µLearn Build a Simple Chatbot Task (250 Karma Points)**.

## ✨ Features

- 🎭 Five AI personas: Tutor, Code Mentor, Creative, Mindfulness, and General Assistant.
- ⚡ Real-time AI response streaming.
- 🧠 Multi-turn conversation memory.
- 🛡️ Offline fallback without an API key.
- 💬 Quick starter prompts.
- 📥 Export conversations as JSON.

## 🛠️ Tech Stack

- Python 3.10+
- Streamlit
- Google Gemini 2.5 Flash
- Google GenAI SDK

## 🚀 Installation

```bash
git clone https://github.com/YOUR_USERNAME/zenith-ai-chatbot.git
cd zenith-ai-chatbot
pip install -r requirements.txt
```

Set your `GEMINI_API_KEY` environment variable or enter it in the app sidebar.

Run the application:

```bash
streamlit run app.py
```
